# קבועים: אפליקציית רשת לתשלומים קבועים (אייפון, ממסך הבית)

אפליקציה בעברית לניהול תשלומים קבועים, שנבנתה לפי הוראות הפרויקט. שומרים אותה מספארי למסך הבית, והיא נפתחת במסך מלא כמו אפליקציה רגילה. כל הנתונים נשמרים רק במכשיר, בלי חשבון, בלי שרת ובלי חיבור לבנק.

## מה יש באפליקציה
- **סקירה:** עלות חודשית קבועה (הסכום הבולט, כולל החלק היחסי של תשלומים שנתיים ורבעוניים) ולצדה החיובים הצפויים החודש לפי סכומים מלאים. מתחת מופיעות תזכורות, ואחריהן רשימת התשלומים עם הסכום המלא, התדירות ומועד החיוב הבא. אפשר לסנן את הרשימה לפי תדירות.
- **לוח:** עיגולי סכום בימי החיוב. מעל הלוח יש פס חודשים לשנה הקרובה עם הסך של כל חודש, כך שרואים מראש חודשים כבדים.
- **הוספה ועריכה:** נפתחות במסך מלא. סוגרים בהחלקה מהקצה הימני או בכפתור "ביטול". מחיקה דורשת אישור בכרטיס, ואחריה אפשר לבטל אותה מההודעה שקופצת.
- **שינוי מחיר וחידוש חוזה:** מוזנים בתוך כל תשלום, ומופיעים בראש מסך הסקירה 60 יום מראש.
- **הגדרות:** מראה (לפי המכשיר, בהיר או כהה), תזכורות, וגיבוי ושחזור לקובץ.

## עדכון גרסה (אוטומטי)
ה־Worker `snowy-queen-2bd3` ב־Cloudflare מחובר למאגר הזה. כל push לענף `main` בונה (`npm run build`) ומעלה (`npx wrangler deploy`) לבד, לפי `wrangler.jsonc`.

**הגדרה חד־פעמית ב־Cloudflare:** Workers & Pages › `snowy-queen-2bd3` › Settings › Builds › Connect, ובוחרים את המאגר.
- Production branch: `main`
- Build command: `npm run build`
- Deploy command: `npx wrangler deploy`
- Root directory: `/`

השם ב־`wrangler.jsonc` חייב להיות זהה לשם ה־Worker, אחרת הבנייה נכשלת.

**באייפון:** אחרי עדכון, האפליקציה מתרעננת לבד בפעם הבאה שפותחים אותה. אם באותו רגע עורכים תשלום, מופיע כפתור "גרסה חדשה · רענון". הנתונים נשמרים באייפון ולא נפגעים מעדכונים.

**אסור לשנות את הכתובת או את שם ה־Worker.** הנתונים באייפון קשורים לכתובת, ובכתובת חדשה האפליקציה תיפתח ריקה.

## החלטות שקיבלתי
- **מבנה הקוד:** הלוגיקה של החישובים (`src/schedule.ts` ו־`src/model.ts`) זהה לזו של גרסת React Native. הממשק נכתב מחדש ב־TypeScript ו־CSS בלי ספריות. ה־CSS וה־JS משולבים בתוך `index.html`, ולכן מספיק לשמור עותק של `/` כדי שהאפליקציה תעבוד בלי רשת.
- **ממשק בעברית מימין לשמאל.** השבוע בלוח מתחיל ביום ראשון, ושישי ושבת מוצללים. סכומים ומספרים מבודדים משמאל לימין.
- **אין שרת, לכן אין תור סנכרון.** אין לאן לשלוח את הנתונים: הם נכתבים ל־localStorage מיד, גם בלי רשת. שורת הסטטוס מציגה "נשמר במכשיר" ואת שעת השמירה האחרונה.
- **מזהה הגרסה:** במקום שרת שמחזיר מזהה גרסה, יש קובץ `/version.json` שנוצר בכל בנייה. ה־service worker אף פעם לא שומר אותו במטמון.
- **התראות:** תזכורת יום לפני חיוב, ושבוע לפני שינוי מחיר או חידוש. מספר הפריטים הקרובים מוצג על אייקון האפליקציה.
  - ההתראות נבדקות כשהאפליקציה נפתחת או חוזרת לחזית. התראה שמגיעה כשהאפליקציה סגורה לגמרי דורשת שרת Web Push, וזה סותר את הדרישה לעבוד בלי שרת. ה־service worker כבר יודע להציג push אם יתווסף שרת כזה בעתיד.
  - באייפון שעוד לא הוסיף את האפליקציה למסך הבית מוצג הסבר איך להוסיף אותה. בקשת ההרשאה מופעלת רק מלחיצה על כפתור.
- **שמירה וגיבוי:** האפליקציה מבקשת `navigator.storage.persist()` כדי להקטין את הסיכוי שהנתונים יימחקו, ויש גיבוי ושחזור לקובץ JSON.
- **נתונים קיימים:** נתונים מאב־הטיפוס ב־HTML (`periodicPayments`) ומגרסת Expo לרשת (`fixedPayments:v2`) נטענים אוטומטית, אבל רק אם הם נשמרו באותו דומיין. נתונים בכתובת אחרת לא עוברים לבד, ואפשר להעביר אותם דרך קובץ גיבוי.
